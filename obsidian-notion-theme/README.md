# Notion Style Theme for Obsidian

一个受 Notion 设计风格启发的 Obsidian 主题，提供干净、简约的阅读和写作体验。

## 安装方法

### 方法一：手动安装

1. 下载 `theme.css` 和 `manifest.json`
2. 在 Obsidian vault 中创建 `.obsidian/themes/Notion Style/` 文件夹
3. 将两个文件复制到该文件夹
4. 在 Obsidian 设置 → 外观 → 主题 中选择 "Notion Style"

### 方法二：直接复制

```bash
# 进入你的 Obsidian vault
cd /path/to/your/vault

# 创建主题文件夹
mkdir -p .obsidian/themes/Notion\ Style

# 复制文件
cp /path/to/obsidian-notion-theme/* .obsidian/themes/Notion\ Style/
```

## 特性

- 🌙 支持亮色/暗色模式
- 📝 清晰的排版层次
- 🎨 Notion 风格的配色
- 📊 美观的表格样式
- 💬 多种 Callout 样式
- ✅ 任务列表样式
- 🔗 链接悬停效果
- 📱 适配移动端

## 配色

### 亮色模式
- 背景：`#ffffff`
- 文字：`#37352f`
- 链接：`#2eaadc`

### 暗色模式
- 背景：`#191919`
- 文字：`#e6e6e5`
- 链接：`#529cca`
